# Glossary

| Term | 中文 | Definition |
| --- | --- | --- |
| argument | 论证 | A claim plus the premises and warrant that support it. |
| contract | 契约 | The three YAML files that make one argument checkable. |
| claim | 主张 | The single conclusion under test, with scope. |
| premise | 前提 | A load-bearing statement. `evidenced` (points at records) or `derived` (points at another argument). |
| warrant | 凭据 | The rule that connects premises to claim, for example `W.rigid-plate-euler`. |
| ceteris paribus condition | 成立条件 | A condition the warrant needs to hold here (structural, temporal, methodological, calibration). |
| defeater | 判废条件 | A way the argument breaks. `undercutting` attacks the inference; `rebutting` attacks the conclusion. |
| entailment | 蕴含 | A consequence that must hold if the claim holds, with a risk rating. |
| coverage | 覆盖 | The fraction of the target area a record actually samples. |
| detectability | 可探测性 | Probability of detecting the feature if it is present. |
| evidence family | 证据族 | Records generated by one physical, methodological, or data channel. |
| independence class | 独立类别 | `physical`, `method`, `data`, or `shared-calibration`. |
| effective evidence count | 有效证据数 | `n_eff = n / (1 + (n-1) * rho_bar)`. |
| discriminating power | 判别力 | Whether a test's outcome differs under the competing hypothesis. |
| decisive test | 决定性检验 | The cheapest test whose outcome changes the verdict now. |
| verdict | 判决 | `SUPPORTED`, `UNDETERMINED`, `UNTESTED`, `SUSPENDED`, `DEFEATED`. |
| gap | 缺口 | Something the contract cannot express, rated `blocking`, `annoying`, or `minor`. |
| registry | 台账 | The hash-chained record written by `geoarg commit`. |
| source locator | 原文锚点 | Page plus the sentence as it appears in the source PDF, carried by transcription-level evidence. |
| grounding gate | 接地门 | `geoarg ground`: a deterministic string check of every declared quote against the source PDF. |
| grounded | 已接地 | The quote occurs on the declared page. Only grounded quotes may stay `accepted` at transcription level. |
| page mismatch | 页码不符 | The quote exists in the PDF but on a different page. A citation error, not a fabrication. |
| not found | 未找到 | The quote occurs nowhere in the PDF. A fabricated draft; the record must become `disputed`. |
| not groundable | 无法接地 | The PDF has no usable text layer, so no quote can be checked. |
| acceptance rate | 验收率 | `grounded / drafted`: the share of declared quotes that the gate found. |
