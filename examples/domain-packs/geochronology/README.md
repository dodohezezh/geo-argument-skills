# Geochronology pack

An eruption-age pack. It adds the `eruption-age` claim kind, two dating methods,
the `eruption-marker` evidence kind and a `same-ash-fall` independence class, and
ships one pattern for an age bracket.

```
geoarg domains examples/domain-packs/geochronology/age-bracket
geoarg advise examples/domain-packs/geochronology/age-bracket
```
